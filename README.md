# 🕵️ DevDetective

DevDetective is a GitHub profile search application that allows users to quickly search for any GitHub username and view detailed profile information in a clean and responsive interface.

## 🚀 Features

* Search GitHub users by username
* View profile picture and name
* Display GitHub username with profile link
* Show bio and account creation date
* View repository, follower, and following counts
* Display location, website, Twitter handle, and company information
* Dark Mode / Light Mode support
* Responsive and modern UI
* Real-time data fetched from the GitHub API

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GitHub REST API

## ⚙️ How It Works

1. Enter a GitHub username in the search box.
2. Click the Search button or press Enter.
3. The application fetches user data from the GitHub API.
4. Profile information is displayed instantly.
5. Toggle between Light Mode and Dark Mode using the theme switcher.

## 🔗 GitHub API Endpoint

```javascript
https://api.github.com/users/{username}
```
